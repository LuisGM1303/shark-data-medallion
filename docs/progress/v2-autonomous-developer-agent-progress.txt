Design decisions:
- content_hash: SHA-256 over canonical JSON (sort_keys, UTF-8, stable NULL,
  deterministic list order); operational fields excluded by the caller.
- rejection_id: SHA256(source | natural_key | reason | record_hash).
- Bronze: append-only, raw_payload STRING. Silver/Gold: MERGE by natural key
  with "WHEN MATCHED AND content_hash <> THEN UPDATE" (content-aware no-op).
- gold.species replaces species_catalog; SpeciesMetadata denormalized into
  gold.species_chunks; species_chunks created with delta.enableRowTracking=true.
- Notebooks use %run ./00_bootstrap for shared setup; src/ wired via sys.path
  with auto-detection of the workspace path (manual fallback documented).
